# ADR-007: 循环中支持用户输入排队

## 状态
已通过

## 背景
Agent 在处理一个请求时（多次调 LLM + 工具，可能持续数秒），用户无法输入新指令。如果 LLM 卡在工具循环中，用户只能干等或 Ctrl+C 重来。

## 方案
选 **方案二：排队**。用户在主循环运行时可以随时打字，输入由后台线程读取并放入队列，等当前 `agent.run()` 结束后自动处理下一条。

**不选方案一（打断）的理由：** 用户插话时前面可能已经执行了几个工具，打断浪费已完成的工作。
**不选方案三（塞入循环）的理由：** LLM 中途看到插话会困惑，上下文混乱。

## 实现要点
- 输入排队由 ADR-009 的 Conversation 层统一实现（Always-on worker + 双队列）
- TUI 入口：Textual 的 Input widget 天然不阻塞，多条输入自动在 `_in` 队列排队
- CLI 入口：`shell.py` 走 Conversation 层，`submit()` 后 poll 循环等 DoneEvent

## 变更范围
- 详见 ADR-009（Core+App 架构）和 ADR-010（TUI）
- 输入排队不再单独实现，而是架构重设计的一部分
