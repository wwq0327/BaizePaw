# v0.5 教练对话

> 日期：2026-05-03
> 目标：让 Agent 作为阅读教练，主动引导学习

---

## 背景

v0.4 建了知识库模块，但 Agent 还不能用知识库来教学。v0.5 让 Agent 读取知识库、讲解知识点、出题检验、评估掌握、记录进度。

---

## 实现

### 新增模块

| 模块 | 文件 | 测试数 |
|------|------|--------|
| COACH.md 角色文件 | `COACH.md` | 验证 load_role 非空 |
| 学习进度 | `src/knowledge/progress.py` | 8 |
| 教练工具 | `src/tools/knowledge_tools.py` | 7 |
| Coach 模块 | `src/coach.py` | 5 |
| TUI 模式切换 | `src/tui/app.py` | 3 |
| Shell 模式切换 | `src/shell.py` | 1 |

### 改造模块

| 模块 | 改动 | 新增测试 |
|------|------|----------|
| ToolDispatcher | `__init__(tools=None)` 可注入 | 2 |
| Core | `__init__(role_path=None, tools=None)` 可注入 | 2 |
| Conversation | `__init__(core=None)` 接受外部 Core | 1 |

### 设计决策

- **Coach 独立 Core**：Coach 创建自己的 Core（COACH.md + 只读工具 + 知识工具），和普通 Chat 的 Core 完全独立
- **教练工具集**：read_file, list_dir, find_file, grep_file, calculator, search + 4 个知识工具（不含 write/delete）
- **懒初始化 Coach**：`/coach` 命令时才创建 coach_conversation，避免无用资源
- **progress.py 语义 API**：mark_mastered/mark_stuck/mark_skipped/set_current，不用裸文件操作
- **双向兼容**：Core/Conversation/ToolDispatcher 的默认值保持原行为，现有代码零改动
