# v0.6 Ingest 功能

## 目标

实现 ingest 功能：把 `knowledge/raw/` 中的 Markdown 书拆成结构化知识库（概念页 + 索引 + 日志），LLM 通过工具自主编排扫描→确认→拆分→收尾流程。

## 实现内容

### 1. Markdown 分块器 `src/knowledge/chunker.py`

- 按 `###` (h3) 标题拆分，无 h3 时回退到 `##` (h2)
- 第一个 `##` 之前的内容作为 `front_matter`
- 跳过 h1（书名），不作为分块
- 超长段落（> max_chars）在段落边界二次分割，无段落分隔时强制按字符数切分
- `chunk_markdown()` 返回带 index/title/chapter/content/char_count 的 dict 列表
- `list_chunks()` 返回不含 content 的元数据概览

### 2. Ingest 工具（4 个新工具）

在 `src/tools/knowledge_tools.py` 中新增：

- `ingest_list_raw` — 列出 raw/ 中的 .md 文件
- `ingest_read_chunk` — 读取指定书的某个分块
- `ingest_write_concept` — 创建概念页 + 更新索引（原子操作）
- `ingest_log` — 记录 ingest 操作日志

工具总数从 4 增至 8。

### 3. COACH.md 新增 Ingest 工作流

四阶段流程：扫描→确认→拆分→收尾。LLM 自主编排，用户在确认阶段干预。

### 4. `/ingest` 命令

Shell 和 TUI 均支持 `/ingest` 命令，自动切换到 Coach 模式并提交扫描指令。

### 5. 测试

- 单元测试：chunker (7), knowledge_tools (13), coach (6)

- E2E 测试：mock LLM 模拟完整 ingest 流程 (1)

## 设计决策

- **先列后拆**：先扫全书列概念清单→用户确认→逐个创建概念页
- **全局扁平**：`knowledge/concepts/` 不按书分目录
- **LLM 自主编排**：不写编排逻辑，LLM 通过工具自己决定何时读、何时写
- **每次只读一个 chunk**：避免上下文溢出

## 已知限制

- 断点续传：扫描中断后需从头开始
- PDF 支持：只处理 Markdown
- 概念合并：第二本书 ingest 时概念名重复会覆盖
- 每帧重复分块：`ingest_read_chunk` 每次调用重新执行 `chunk_markdown`
