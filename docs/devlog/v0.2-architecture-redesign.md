# v0.2 架构重设计

## 概要

从单体 `AgentRunner` 拆为三层：表现层 → Conversation 桥接层 → Core(Pipeline)。

## 变更

### 新增文件
- `src/event.py` — Event 体系（ToolEvent / DoneEvent / ErrorEvent）
- `src/pipeline.py` — Plugin 基类 + Pipeline + LoggerPlugin
- `src/core.py` — Core.run_iter() 生成器，从 agent.py 迁移逻辑
- `src/conversation.py` — Always-on worker + _in/_out queue 桥接层
- `src/tui/app.py` — Textual TUI（RichLog + Input + Status）
- 对应测试文件

### 修改文件
- `src/tools/file_ops.py` — 去掉 print() 污染，命令信息嵌入返回字符串
- `src/shell.py` — 走 Conversation 层
- `main.py` — 默认 TUI，`--cli` 走 CLI

### 标记废弃
- `src/agent.py` — DEPRECATED，用 Core 替代

## 架构

```
TUI / CLI (表现层)
    ↓ submit() / poll()
Conversation (桥接层, worker thread + queue)
    ↓ run_iter()
Core (Pipeline)
    ↓ yield Event
    ChatHistory + LLMClient + ToolDispatcher
```

## 踩坑

- Event 需要 Union 类型别名 `Event = Union[ToolEvent, DoneEvent, ErrorEvent]`，Pipeline 依赖它做类型标注
- Conversation 的 worker 用 `daemon=True`，`_in.get(timeout=0.5)` 避免死锁，stop 时用 None sentinel 唤醒
- Textual `set_interval(0.1)` 轮询 Conversation，10fps 足够流畅
