# v0.4 知识库构建

> 日期：2026-05-03
> 目标：把一本书变成 LLM 维护的 interlinked markdown 知识库

---

## 背景

v0.3 角色系统完成后，Agent 有了人格但没有"大脑"——它不知道任何书的内容。v0.4 目标是建一个纯 markdown 的知识库系统，Agent 可以把书拆成知识点，每个知识点一个 md 文件，互相引用，git 可追踪。

---

## 实现

### 模块结构

```
src/knowledge/
├── __init__.py    # init_knowledge_dir() — 创建 knowledge/ 目录结构
├── schema.py      # load_schema() — 读取 KNOWLEDGE_SCHEMA.md
├── concept.py     # create/read/update/delete_concept()
├── index.py       # add_to_index / read_index / remove_from_index
└── log.py         # append_log / read_log
```

### 四个 Task

| Task | 文件 | 测试数 |
|------|------|--------|
| 目录结构 + Schema | `KNOWLEDGE_SCHEMA.md`, `__init__.py`, `schema.py` | 2 |
| 概念页 CRUD | `concept.py` | 4 |
| 索引管理 | `index.py` | 3 |
| 日志管理 | `log.py` | 2 |

### 设计决策

- **纯文件系统**：知识库就是 markdown 文件 + 目录，不引入数据库
- **Schema 分离**：页面模板和命名约定放在 `KNOWLEDGE_SCHEMA.md`，改规则不改代码
- **Concept CRUD 极简**：create 自动加标题，update 全量覆写，delete 直接删文件
- **Index 防重复**：`add_to_index` 检查条目是否已存在，避免重复追加
- **Log 时间戳**：`append_log` 自动加 `[YYYY-MM-DD HH:MM]` 时间戳
