# 读书教练：陪伴式学习 Agent

> 日期：2026-05-03
> 状态：方案已确认，待进入实现计划

---

## 核心理念

传统知识付费 = 一本书扔给你，自己看。未来的学习工具 = 像教练一样陪在你身边，一步步引导，实时反馈，动态调整。

核心理念来自 Dan Koe 等人的知识分享：**从"一次性交付"变成"陪伴式教练"**。

---

## 产品形态

用户给 BaizePaw 一本书（PDF / Markdown），Agent 不再是"读完给摘要"，而是：

1. 把书拆成结构化知识库（知识点 + 关系网络）
2. 按两种模式引导学习
3. 全程提问、检验、评估、调整
4. 最终以作品/项目验证掌握

互动模式：苏格拉底式引导对话。Agent 主动引领，用户回应，Agent 根据回应动态推进。

---

## 两种学习入口

### 模式 A：探索模式（"不知道这本书跟我有什么关系"）

- Agent 先提取全书核心概念
- 围绕核心概念打散章节、重组知识点
- 以知识点为线索组织学习路径
- 每个知识点：先解释概念 → 提问检验 → 基础练习 → 反馈

### 模式 B：目标驱动模式（"我想用这本书解决 X 问题"）

- 用户说出目标
- Agent 从书中提取相关知识点
- 定制一条从基础到目标的路径
- 完成标准：用户提出的实际问题得到解决

---

## 学习闭环

```
Agent 引导读知识点
    ↓
Agent 出题检验理解
    ↓
用户回答 / 实操
    ↓
Agent 反馈：对错、偏差、改进建议
    ↓
通过 → 进入下一个知识点
未通过 → 回到相关内容重读
    ↓
所有知识点完成 → 项目/作品验证 → 毕业
```

---

## 毕业标准

- 有明确目标：实际问题是否解决
- 无明确目标：Agent 出一个项目/题 → 用户完成 → Agent 评估通过

## 分阶段实现

### v0.4 — 知识库构建

**目标**：把一本书变成 LLM 维护的 interlinked markdown 知识库（按 LLM Wiki 模式）

**Ingest 流程**：

1. 用户把书（PDF/MD）放入 `knowledge/raw/`
2. 触发 ingest：Agent 提取文本 → 识别知识点 → 每个知识点一个 md
3. Agent 建交叉引用 → 写 index.md → 追加 log.md

**产出结构**（pure markdown，git 可追踪）：

```
knowledge/
├── raw/                          # Raw sources（不可变）
│   └── python-handbook.pdf
├── python-handbook/              # The wiki（Agent 维护）
│   ├── index.md                  # 索引：所有知识点 + 一行摘要
│   ├── log.md                    # 时间线：ingest / lint 记录
│   ├── concepts/                 # 知识点页面
│   │   ├── variables.md
│   │   ├── functions.md
│   │   └── ...
│   ├── comparisons/              # 对比页（如 list-vs-tuple.md）
│   └── synthesis.md              # 全书要点合成
└── KNOWLEDGE_SCHEMA.md           # Schema：模板 + 命名约定 + 关联规则
```

**不包含**：教练对话、学习路径、用户状态追踪、COACH.md 角色

### v0.5 — 教练对话

**目标**：基于知识库，Agent 作为阅读教练主动引导学习

**核心能力**：

- 加载 v0.4 知识库 + 加载 `COACH.md` 教练人格
- 两种模式入口（探索 / 目标驱动）
- 知识点引导 → 提问 → 评估 → 调整 → 进度记录

**教练互动设计**：

| 场景    | 设计                                         | 决策                      |
| ----- | ------------------------------------------ | ----------------------- |
| 首次接触  | 开场问用户基础水平，让用户自己决定从哪开始                      | 3 选项：零基础 / 有基础 / 跳过基础   |
| 跨会话记忆 | `progress.md`（结构化进度）+ ChatHistory（对话连续性）结合 | 下次打开自然接上                |
| 进度可见  | 每次开头一句话总结 + `progress.md` 可随时查看            | 已掌握 ✓ / 卡住 ✗            |
| 卡住处理  | 标记跳过，不卡死                                   | "先放一放，后面用到再回来看"         |
| 教练人格  | 独立 `COACH.md` 角色文件，和 AGENT.md 分开           | 温暖鼓励型，有温度但不啰嗦           |
| 模式切换  | `/coach` 进教练模式，`/chat` 回普通模式               | 同一 TUI，输入命令切换，状态栏显示当前模式 |

**学习状态文件**（`knowledge/{book}/progress.md`）：

```markdown
# 学习进度：Python Handbook

> 最后更新：2026-05-03 14:30

## 掌握
- [x] variables
- [x] functions
- [x] loops

## 卡住
- [ ] decorators（3次未通过，暂跳过）

## 当前
→ 正在学：list comprehensions

## 会话历史
- 2026-05-02 学了 variables, functions
- 2026-05-03 学了 loops，decorators 跳过
```

## 知识库架构（基于 LLM Wiki 模式）

参照 [LLM Wiki](https://github.com/tobi/llm-wiki) 的三层架构：

```
Raw Sources (不可变)     →  The Wiki (Agent 维护)    →  Schema (规则)
    书 PDF / MD              markdown 文件集合           KNOWLEDGE_SCHEMA.md
```

### 三层映射

| LLM Wiki 层                            | 读书教练实现                                        |
| ------------------------------------- | --------------------------------------------- |
| **Raw sources** — 原文不改                | 用户给的 PDF/Markdown 书，只读不写                      |
| **The wiki** — LLM 维护的 interlinked md | `knowledge/{book}/` 知识点页面、概念页、index.md、log.md |
| **The schema** — 规则约定                 | `KNOWLEDGE_SCHEMA.md` 定义页面模板、命名约定、关联规则        |

### 用户视角：只需两个动作

| 动作             | 用户做什么                                         | Agent 自动完成                                             |
| -------------- | --------------------------------------------- | ------------------------------------------------------ |
| **1. 给书 + 目标** | 把书（PDF/MD）给 Agent，说想学什么（或不给目标，让 Agent 围绕核心引导） | 解析文本 → 拆知识点 → 建 wiki → 写索引 → 交叉引用 → log 记录。全程自动        |
| **2. 被教练带着走**  | 回应用户的提问、做练习、接受反馈                              | 按知识库主动引导提问 → 评估回答 → 给出反馈 → 动态调整路径。用户可主动问，但**教练引导是主模式** |

### 关键洞察

- **教练主动，不是用户主动** — 新手不知道自己不知道什么，等用户来问就失去价值了。Agent 必须按知识库体系主动提问、主动引导
- **评估也是 Agent 做** — 用户不用自检"我学会了没"，Agent 出题、看回答、判断掌握程度、决定要不要回退
- **中间全自动** — Ingest、Lint、索引维护、知识库更新，用户不感知这些操作的存在
- 知识库是累积的：第二本书合并进已有知识库，概念页自动更新
- 知识库是文件系统：纯 markdown，git 版本控制，Obsidian 可浏览

## 技术决策（已确认）

| 决策        | 选择                               | 理由                         |
| --------- | -------------------------------- | -------------------------- |
| 目录结构      | **全局扁平** — `knowledge/concepts/` | 跨书概念自然合并                   |
| Ingest 粒度 | **先列后拆** — 先扫全书出概念清单，用户确认后再逐个拆   | 符合教练主动引导理念                 |
| PDF 解析    | **暂不支持** — v0.4 只处理 Markdown     | PDF 需求不紧迫                  |
| 教练对话      | **独立模块** — `src/coach.py`        | 与 Conversation 解耦，独立管理对话循环 |
| 记忆方案      | **文件优先** — JSON 会话 + progress.md | 当前量级不需要 Mem0/A-mem         |
