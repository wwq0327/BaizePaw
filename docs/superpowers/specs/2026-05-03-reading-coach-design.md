# 读书教练：陪伴式学习 Agent

> 日期：2026-05-03
> 状态：设计中

---

## 核心理念

传统知识付费 = 一本书扔给你，自己看。未来的学习工具 = 像教练一样陪在你身边，一步步引导，实时反馈，动态调整。

核心理念来自 Dan Koe 等人的知识分享：**从"一次性交付"变成"陪伴式教练"**。

---

## 产品形态

用户给 BaizePaw 一本书（PDF / Markdown），Agent 不再是"读完给摘要"，而是：

1. 把书拆成结构化知识库（知识点 + 关系网络）
2. 按两种模式引导学习
3. 全程提问、检验、评估、调整
4. 最终以作品/项目验证掌握

互动模式：苏格拉底式引导对话。Agent 主动引领，用户回应，Agent 根据回应动态推进。

---

## 两种学习入口

### 模式 A：探索模式（"不知道这本书跟我有什么关系"）

- Agent 先提取全书核心概念
- 围绕核心概念打散章节、重组知识点
- 以知识点为线索组织学习路径
- 每个知识点：先解释概念 → 提问检验 → 基础练习 → 反馈

### 模式 B：目标驱动模式（"我想用这本书解决 X 问题"）

- 用户说出目标
- Agent 从书中提取相关知识点
- 定制一条从基础到目标的路径
- 完成标准：用户提出的实际问题得到解决

---

## 学习闭环

```
Agent 引导读知识点
    ↓
Agent 出题检验理解
    ↓
用户回答 / 实操
    ↓
Agent 反馈：对错、偏差、改进建议
    ↓
通过 → 进入下一个知识点
未通过 → 回到相关内容重读
    ↓
所有知识点完成 → 项目/作品验证 → 毕业
```

---

## 毕业标准

- 有明确目标：实际问题是否解决
- 无明确目标：Agent 出一个项目/题 → 用户完成 → Agent 评估通过

---

## 分阶段实现

### v0.4 — 知识库构建

**目标**：把 PDF / Markdown 拆成结构化知识库

- 解析 PDF / Markdown 提取文本
- 识别核心概念 + 知识点
- 打散章节，按概念重组
- 生成本地知识库文件（JSON 或其他结构）

**不包含**：教练对话、学习路径、用户状态追踪

### v0.5 — 教练对话

**目标**：基于知识库，Agent 作为教练引导学习

- 加载 v0.4 生成的知识库
- 两种模式入口（探索 / 目标驱动）
- 知识点引导 → 提问 → 评估 → 调整
- 项目/作品验证
- 学习状态追踪
